# MR

A merge request is GitLab's name for a pull request, so an MR description is a PR body. The `pr` skill owns its structure. This skill only carries the GitLab word so an agent writing an MR finds that structure. `pr` is synced from `mattpocock/skills`, so its own description can't take the word without the next `npx skills update` dropping it.

Load the `pr` skill and follow it exactly as written. Read "PR" as "MR" throughout.
