# Work-context skills may live in this personal skills repo

This repo was assumed to be employer-agnostic — no generic skill here hardcodes a specific company's GitLab/Jira project. During reconciliation with an older work-computer skills folder, that assumption was tested: a cluster of skills (`_studio-*`, `atlassian`, `_shared`) are tightly coupled to Eric's current employer's Studio GitLab project and Jira instance.

Decided to keep them here anyway. Eric's employer enforces strict guardrails on which skills can be added to the Studio monorepo itself, so this personal repo is the only practical place to iterate on Studio-specific agent skills. The alternative — a separate work-only skills location — was rejected because it would fragment where Eric's day-to-day work skills actually live, for no real benefit now that the Studio-coupling is explicit and tracked (see `docs/skills-reconciliation.md`).

Consequence: this repo is not purely employer-agnostic. Work-context skills are a distinct, explicitly-labeled category (see `CONTEXT.md`), reviewed on their own terms rather than assumed generic.
